# 🎯 סוכן קורות חיים חכם

אפליקציה שמנתחת את קורות החיים שלך, מחפשת משרות רלוונטיות באינטרנט, כותבת מייל
מותאם אישית לכל חברה — ושולחת **רק אחרי שאתה מאשר**.

## איך זה עובד

```
1. העלאת קו"ח  →  2. הסוכן בונה פרופיל  →  3. חיפוש משרות (חיפוש באינטרנט)
   →  4. לכל חברה: מייל מותאם  →  אתה עורך ומאשר ✓  →  שליחה  →  5. מעקב
```

- **חיפוש עצמאי** — הסוכן מחפש משרות פתוחות בעצמו לפי הפרופיל שלך.
- **שליחה עם אישור** — שום מייל לא נשלח בלי שתאשר אותו ידנית.
- **מייל מותאם לכל חברה** — לא הודעה גנרית.

## דרישות

| מה | לשם מה | איפה משיגים |
|----|--------|-------------|
| `ANTHROPIC_API_KEY` | ניתוח, חיפוש וכתיבה | https://console.anthropic.com |
| `RESEND_API_KEY` | שליחת המיילים בפועל | https://resend.com (חינמי עד 3,000/חודש) |
| `FROM_EMAIL` | כתובת שולח מאומתת | דומיין מאומת ב-Resend |

## התקנה מקומית

```bash
cd resume-agent
npm install
cp .env.example .env    # מלא את המפתחות
```

הרצה (שני תהליכים — הפרונט וה-serverless):

```bash
# מריץ גם את הפרונט וגם את פונקציות ה-API יחד
npx vercel dev
```

או בנפרד: `npm run dev` (פרונט) לצד `vercel dev` (API על פורט 3000 — הפרוקסי כבר מוגדר).

## פריסה ל-Vercel

1. חבר את התיקייה `resume-agent` כפרויקט חדש ב-Vercel.
2. הגדר את משתני הסביבה (`ANTHROPIC_API_KEY`, `RESEND_API_KEY`, `FROM_EMAIL`, ובאופציונלי `ANTHROPIC_MODEL`) בהגדרות הפרויקט.
3. פרוס (`vercel --prod`).

```
│   └── main.jsx
└── ...
```

## הערות

- **מפתחות API נשמרים רק בצד השרת** (משתני סביבה) — לעולם לא בקוד ולא בדפדפן.
- מייל שנשלח לא ניתן לביטול. הסוכן מציג לך תצוגה מקדימה מלאה לפני כל שליחה.
- חיפוש המשרות עשוי לקחת עד דקה (חיפוש אמיתי באינטרנט מרובה שלבים).
- אם לא נמצאה כתובת מייל לחברה, האפליקציה תיצור עבורך את המייל להעתקה והגשה ידנית.
- כדי להשתמש בדגם חזק יותר, שנה את `ANTHROPIC_MODEL` במשתני הסביבה.
