# מכולת חכמה 🛒

אפליקציית PWA לניהול חכם של מכולת.

## התקנה מקומית

```bash
npm install
npm run dev
```

## פריסה ל-Vercel

```bash
npm install -g vercel
vercel --prod
```

## הוספה לפלאפון

### אייפון (iOS Safari):
1. פתח את כתובת האפליקציה ב-Safari
2. לחץ על כפתור השיתוף ⬆️
3. בחר "הוסף למסך הבית"
4. לחץ "הוסף"

### אנדרואיד (Chrome):
1. פתח את כתובת האפליקציה ב-Chrome
2. לחץ על תפריט ⋮
3. בחר "הוסף למסך הבית"
4. לחץ "הוסף"
